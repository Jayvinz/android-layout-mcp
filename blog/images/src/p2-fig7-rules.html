Twelve rules, four kinds of evidence
Every rule reads a different field of the node. That is why the last group only fires on a capture that asked for raw View properties.
Geometry
Measured from bounds and visibleBounds.
zero_sizeWARN
0x0
offscreenWARN
outside the screen
small_touch_targetWARN
< 48dp
outside_parentWARN
escapes a fixed parent
Visibility
What the clip rectangle and the screen edge hide.
clippedINFO
visibleBounds cut
invisible_clickableWARN
can be tapped, cannot be seen
overlapWARN
two clickables share pixels
Identity
What the node says about itself, or fails to say.
unlabeled_clickableINFO
no text, desc, or id
duplicate_idWARN
same id, many nodes
deep_nestingINFO
depth past the limit
Raw properties
Needs the debug dump, not accessibility.
overdrawINFO
opaque on opaque
rtl_issuesWARN
hard-coded left / right
composedeep_nesting is skipped on the Compose source. Wrapper depth there is an artifact of how the runtime builds the tree, so a limit would flag every screen.
