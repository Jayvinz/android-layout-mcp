JDWP-Handshake
Both sides answer with the same 14-byte string before any command runs. JDWP allows one debugger per process.
2 · which window
VULW — list windows
names, in creation order
Creation order is not z-order, so the window behind a translucent activity can come first. The focused one is picked from mCurrentFocus.
3 · dump one window
VURT — dumpv2 payload
windowName skipChildren=0 includeProperties=1 v2 protocol=1
one buffer of tagged values
The app walks its own hierarchy inside the debugger call, then resumes the VM, so it keeps rendering while the tree is read.
